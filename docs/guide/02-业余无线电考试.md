# 📝 业余无线电考试（操作能力验证）

### 一、设台与使用的基本条件
设置、使用业余无线电台，须**同时满足**以下条件：

1. 熟悉无线电管理相关法律法规；
2. 通过操作技术能力验证，**取得对应类别证书**；
3. 发射设备合规：
   - 已取得**型号核准**（含业余频段）；**或**
   - 自制/改装设备（无型号核准，但符合国标、仅限业余频段）。

> 依据：《业余无线电台管理办法》第七条



### 二、操作证书类别与报考条件
证书分为 **A、B、C 三类**，逐级报考、权限递增。

#### 🟢 A 类（基础级）
- 报考条件：熟悉法规，具备**基础操作能力**；
- 权限：V/U 频段，适合入门、U/V频段；

#### 🟡 B 类（进阶级）
- 报考条件：**持 A 类执照满 6 个月**，有实际通联经验；
- 权限：开放HF频段，可在许可的全部业余波段合规通联；

#### 🔴 C 类（专业级）
- 报考条件：**持含 30MHz 以下频段执照满 18 个月**；
- 权限：可在许可的全部业余波段合规通联、更高功率，适合 DX、实验、竞赛；

> 依据：《业余无线电台管理办法》第二十五条、第二十六条



### 三、考试与证书要点
- 考试由**国家/省级无线电管理机构**组织；
- 合格后发放《**业余无线电台操作技术能力验证证书**》；
- 证书**全国有效**，是申请电台执照的必要材料；
- 禁止**无证发射、超类别操作、跨频段违规使用**。
