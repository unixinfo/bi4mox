# 📻 业余无线电设台以及使用许可

### 业余无线电设台
常见的业余无线电台从形式上可分为：手持对讲机（手台）、车载电台、基地固定电台等。

### 设备要求
设置业余无线电台使用的无线电发射设备需满足以下任一条件：
1. 依法取得型号核准（型号核准证载明的频率范围包含业余业务频段）；
2. 自制/改装/拼装等未取得型号核准的设备，需符合国家标准和国家无线电管理规定，且发射频率范围仅限于业余业务频段。

### 特殊人群限制
未成年人仅可设置、使用工作在 30-3000MHz 频段且最大发射功率不大于 25 瓦的业余无线电台。

### 执照与呼号要求
设置的业余无线电台需取得业余无线电台执照及电台呼号。

### 操作类别与发射功率限制
不同操作类别对应的设台/使用权限如下：

| 操作类别 | 频段范围       | 最大发射功率       | 备注 |
|----------|----------------|--------------------|-----------------------------------|
| A类      | 30-3000MHz     | ≤25 瓦             | U/V段/6米                                 |
| B类      | 30MHz以下      | <15 瓦             | 2024年3月1日前取得B类证书≤100 瓦  |
| B类      | 30MHz以上      | ≤25 瓦             |  U/V段/6米 |
| C类      | 30MHz以下      | ≤1000 瓦           | -                                 |
| C类      | 30MHz以上      | ≤25 瓦             | U/V段/6米                                 |

> 引自《业余无线电台管理办法》第三十条。
