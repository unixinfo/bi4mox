# 📜 业余无线电法律法规

### 🔹 核心法规文件
以下为业余无线电爱好者必须遵守的国家及地方法律法规，是合法设台、合规通联的重要依据。

- 《中华人民共和国无线电管理条例》
- 《业余无线电台管理办法》
- 《中华人民共和国无线电频率划分规定》
- 《山东省无线电管理条例》

### 🔹 重点遵守事项
1. **必须取得相应操作证书且取得业余无线电台执照和呼号；**
2. **严禁使用非核准设备、超功率、超频段发射；**
3. **严禁从事商业通信、违法通联及恶意干扰；**
4. **中继台、固定台必须依法申请、合规架设；**
5. **通联内容需文明、合法、遵守业余无线电公约；**
